Run the final application

Download the database ZIP, extract it, and open a terminal in its top-level folder. Requirements: C++17 compiler, SQLite 3 development headers and library; CMake 3.16+ for the first path. The direct commands below are for macOS/Linux with c++. On Linux, install your distribution's SQLite development package if sqlite3.h is missing.

CMake path

cmake -S enhanced -B build
cmake --build build
ctest --test-dir build --output-on-failure
./build/tree_benchmark
./build/course_planner course_catalog.db

Direct compile fallback (no CMake)

mkdir -p build-direct
c++ -std=c++17 -Wall -Wextra -Wpedantic -Ienhanced/include enhanced/src/Repository.cpp enhanced/src/Database.cpp enhanced/src/Tree.cpp enhanced/src/Service.cpp enhanced/src/Menu.cpp enhanced/src/main.cpp -lsqlite3 -o build-direct/course_planner
c++ -std=c++17 -Wall -Wextra -Wpedantic -Ienhanced/include enhanced/src/Repository.cpp enhanced/src/Database.cpp enhanced/src/Tree.cpp enhanced/src/Service.cpp enhanced/src/Menu.cpp enhanced/tests/tests.cpp -lsqlite3 -o build-direct/planner_tests
c++ -std=c++17 -Wall -Wextra -Wpedantic -Ienhanced/include enhanced/src/Tree.cpp enhanced/benchmarks/tree_benchmark.cpp -o build-direct/tree_benchmark
./build-direct/planner_tests
./build-direct/tree_benchmark
./build-direct/course_planner course_catalog.db

For Visual Studio multi-configuration builds, use cmake --build build --config Debug, ctest --test-dir build -C Debug --output-on-failure, and build/Debug/course_planner.exe course_catalog.db. SQLite development files must be discoverable by CMake. This Windows path is documented, not verified on this macOS test environment.

Small demonstration

Choose 1 and enter sample_courses.csv. Choose 2 to list five courses. Choose 3 and enter csci400 to find its prerequisites. Options 4, 5, and 6 create a course, update a title, and delete a course. Exit with 9 and reopen the same database path to see that data remains. Import replaces the whole catalog; make a copy of a real database before trying a replacement import.
