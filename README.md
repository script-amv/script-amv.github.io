# Dmitrii Shostak — CS 499 ePortfolio

Live portfolio: https://script-amv.github.io/

The home page presents the professional self-assessment first. The code review,
three enhancement pages, outcome map, and Files & Tests page explain one CS 300
Course Planner from its original version through C++ design, AVL algorithms,
and SQLite persistence. Narratives are readable online and available as Word
documents. Source files can be read in the source viewer.

`artifacts/` holds original and enhanced code snapshots, sample data, build
instructions, and final verification records. `downloads/` holds project ZIPs,
narratives, self-assessment, and portfolio URL. `assets/code-review.mp4` is the
submitted code review, hosted directly here.

SQLite runs the final catalog. The AVL is a separate tested algorithm sample,
not a SQLite query engine. Each stage has CMake and direct compiler instructions.
The documented macOS test results do not claim that all platforms were tested.

Preview: run `python3 -m http.server 8000` here and open http://localhost:8000/.
HTTP is needed for the source viewer. GitHub Pages publishes the root of `main`.
