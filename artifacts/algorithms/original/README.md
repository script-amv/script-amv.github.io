# CS-300

In the projects for this course, I worked on solving a problem for academic advisors at ABC University. The advisors needed computer program to help them access course information and prerequisites quickly while talking to students. The program had to read course data from a file,store it efficiently, print a sorted list of all courses and look up individual course details. I approached this problem by studying and designing different data structures like vectors, hash tables and binary search trees. Understanding data structures is very important because choosing the wrong one can make program slow or use too much  memory. For example, sorting a vector takes more time than using a binary search tree which is naturally sorted.
While working on these projects, I encountered some roadblocks, especially when writing the code for removing nodes from a binary search tree and  handling collisions in the hash table. Pointers in C++ can be very confusing and it's easy to make mistakes that crash the program or leak memory. I overcame these challenges by tracing my code on paper, writing down steps of the algorithms and using the debugging tools in Visual Studio to watch pointers change. This experience has expanded my approach to designing software. Now I spend much more time planning with pseudocode before I write any code. I learned that designing the program  first actually saves lot of time because I don't have to spend hours debugging bad logic. My work on these assignments has also changed the way I write programs. I used to just write code that works, but now I focus on making it readable and maintainable.
I make sure to use camelCase for my variables, add helpful in-line comments and separate my logic into small, modular functions. For example, separating  the file parsing logic from the data structure  logic makes the program much easier to update. This makes my code adaptable so that if the university wants to change the file format or add new features in the future, it can be done without rewriting the entire program from scratch.
